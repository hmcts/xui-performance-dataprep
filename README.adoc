### Data-prep script for XUI performance testing

To run locally:
- Run against the perftest environment: `./gradlew gatlingRun`

##Inputs

1. In the simulation file, amend the following accordingly:

- rampUpDurationMins: the time to ramp up users (one user is run per org created)
- numberOfOrgsToCreate: number of organisations to create
- numberOfSolicitorsPerOrg = number of solicitors (users) to add per organisation (excluding the org admin user)

2. In the scenario file, amend the following:

- line 25: set the string prefix used to name the org and users based on the service e.g. "perf-prl-"

##Outputs:

1. The generated data (orgs/users/passwords) are output to src/gatling/output/UserDetails.csv
